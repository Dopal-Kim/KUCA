## 0. 원문 정리

### 산책 추천 (12개) → 네 묶음
| 묶음 | 원문 항목 | 한 줄 요약 |
| --- | --- | --- |
| **A. 무엇을 추천하나** | 1 취향 우선(체크리스트) · 2 계절과 시간 · 3 실시간 거리 우선 · 6 산책 시간 30분/1시간 | 취향 > 계절·시간 > 지금 위치에서 가까운 순으로 코스를 고른다 |
| **B. 누구와 걷나** | 4 매칭 스팟(경희몬 배치 + 스몰토크 주제) · 5 동성 or 랜덤 · 9 오늘의 인상착의 | 근처 사람과 매칭 → 경희몬이 있는 스팟에서 만남 → AI 가 대화 주제를 줌 |
| **C. 걷는 동안·후** | 7 헬스 데이터(칼로리) · 8 혈당 스파이크 줄이기 · 10 산책 중 사진 · 11 오늘 경험 리뷰 | 건강 수치·사진·리뷰로 산책을 기록 |
| **D. 오래 하게** | 12 레벨 10 이 되면 직접 코스 만들어 올리기 | 고레벨 사용자가 코스를 만들고 공유 |

### 경희몬 수정
| 원문 | 뜻 |
| --- | --- |
| 1 포획 기능 삭제 | 지도에서 잡기·AR 잡기 화면을 없앤다 |
| 2 자연 발생 없앰 | 지도에 경희몬이 저절로 나타나지 않는다 |
| 3 처음에 한 마리 주고 걸으면 점점 진화 | 시작 파트너 1마리 → 걸은 거리로 진화 |
| C~A → 티켓 1개 · B~S → 티켓 5개 · 뽑고 진화 가능 | <kbd>해석</kbd> **티켓 1장 뽑기 = C~A 등급 중 하나, 티켓 5장 뽑기 = B~S 등급 중 하나.** 뽑은 경희몬도 걸어서 진화한다 |

> 한 줄로: **"잡는 게임"에서 "같이 걷고 키우는 게임"으로.** 걷기가 티켓·진화·레벨의 유일한 연료가 되고, 사람과 함께 걸으면 더 빨리 큰다.

## 2. 기능 명세 초안

### 2-1. 경희몬 v2 (뽑기·진화)
| 항목 | 초안 | <kbd>결정</kbd> |
| --- | --- | --- |
| 등급 | C · B · A · S (24종을 나눔, S 는 랜드마크 동물 위주) | 등급별 종 수 |
| 시작 | 첫 실행에 C 등급 3마리 중 1마리 고르기 → 파트너 | 고르기 / 무작위 |
| 티켓 얻기 | 혼자 1km = 1장 (하루 3장) · **함께 걷기 완료 = 3장** · 리뷰 작성 = 1장 | 수치 |
| 뽑기 | 1장: C 60% · B 30% · A 10% / 5장: B 60% · A 30% · S 10% | 확률표 (공개 필수) |
| 중복 | 같은 종이 또 나오면 그 종의 진화 경험치로 바뀜 | 중복 처리 |
| 진화 | 3단계 (아기 → 성장 → 완성). 파트너로 함께 걸은 거리로: 1→2 5km, 2→3 20km (등급이 높을수록 더 멀리) | 단계 수·거리 |
| 진화 모습 | 1차: 같은 모델의 크기·빛·이름이 바뀌고 액세서리 슬롯이 열림 · 2차(여유): S 등급만 진화 모델 따로 | 아트 범위 (A) |
| 계절·시간 | 그 시간대·계절에 어울리는 종의 뽑기 확률 ×1.5 (`SpawnConditions` 규칙 재사용) | 쓸지 여부 |

> 확률형 뽑기는 **확률표를 화면에 공개**합니다. 돈으로 사는 티켓은 만들지 않습니다(걷기로만 얻음). 발표에서 "도박성 없음, 걷기 보상"으로 설명하기 좋습니다.

### 2-2. 산책 추천 v2
**입력:** 취향(체크리스트) · 산책 시간 30/60분 · 지금 위치 · 시간대 · 계절 · 날씨 · 이미 가 본 곳
**점수:** `취향 일치 × 3 + 계절·시간 어울림 × 2 + 가까움 × 1` (규칙 추천과 AI 후보 고르기에 같이 씀)

| 기능 | 초안 |
| --- | --- |
| 코스 길이 | 30분 ≈ 2km · 60분 ≈ 4km (걷기 속도 취향 slow/normal/fast 로 보정) |
| AI 의 역할 | 점수 상위 후보 중 코스를 고르고 **장소마다 이유 한 줄** (소개글·계절·날씨에서만) |
| 칼로리 (원문 7) | 1차: 걸은 거리 × 체중(선택 입력, 없으면 60kg) × 0.9 ≈ kcal 로 추정 표시 · 2차: 폰 걸음 센서(Unity Input System `StepCounter`) |
| 식후 걷기 모드 (원문 8) | 점심·저녁 식후 시간대에 "식후 15분 산책" 코스 제안 + 알림. **"일반 건강 정보이며 의료 조언이 아님"** 문구 |

<kbd>결정</kbd>
- 칼로리에 체중을 받을지 (안 받으면 "약 ○○kcal" 로만)
- 식후 걷기 근거 자료를 기획서에 넣을지 (A 가 논문·기관 자료 확인)

### 2-3. 산책 매칭 (실시간)
```
"지금 같이 걷기" 누름 (조건: 시간 30/60, 성별 동성/상관없음)
 → 서버 대기열에 들어감 (내 위치는 건물 단위로만 저장)
 → 서버가 가까운 사람 + 취향 점수로 짝 제안 (2명, 여유 있으면 3~4명)
 → 둘 다 수락
 → 만남 스팟 결정: 두 사람 사이의 경희스팟 → 그 자리에 경희몬이 서 있음 (지도 표시)
 → 각자 "오늘의 인상착의" 한 줄 입력 → 상대에게만 보임
 → AI 스몰토크 주제 3개 (두 사람 취향 공통점 + 스팟 소개 + 날씨)
 → 함께 산책 (추천 코스) → 중간에 사진
 → 완료 → 리뷰 → 티켓·경험치·진화
```

| 항목 | 초안 | <kbd>결정</kbd> |
| --- | --- | --- |
| 거리 | 같은 구역(약 300m) 안 우선, 없으면 캠퍼스 전체 | 범위 |
| 대기 시간 | 5분 안에 못 찾으면 "혼자 걷고 티켓 받기" 로 안내 | 시간 |
| 성별 (원문 5) | 프로필 성별(로그인 때) + "동성만 / 상관없음" 선택. 상대 성별은 매칭 전에 안 보임 | 수집 여부·표시 방식 |
| 인상착의 (원문 9) | 한 줄 글 (예: "검은 후드, 흰 운동화"), AI 검사, **산책 끝나면 삭제** | 사진 허용 여부 (제안: 글만) |
| 스몰토크 (원문 4) | 주제 3개 + 첫 마디 예시. 산책 중 "다음 주제" 버튼 | 톤 |
| 안전 | 낮 시간·공개된 스팟만 · 신고/차단 · 리뷰 별점 낮으면 매칭 제외 · 위치 공유는 산책 중에만 | 운영 시간 (예: 9~21시) |
| 노쇼 | 10분 안에 스팟 도착 안 하면 자동 취소, 반복 시 하루 매칭 제한 | 규칙 |

### 2-4. 산책 중·후
| 기능 | 초안 |
| --- | --- |
| 사진 (원문 10) | 기존 사진 화면 + **파트너 경희몬 AR 로 함께 찍기** (`CatchCameraScreen` 재사용). 앨범·스팟 쪽지로 남기기 |
| 완료 판정 | 코스 마지막 스팟 도착 또는 예정 거리 80% 이상 |
| 리뷰 (원문 11) | 별점(상대·코스 따로) + 한 줄 "오늘 경험은?" → AI 검사. 상대 별점은 상대에게 보이지 않고 매칭 품질에만 씀 |
| 보상 | 티켓 3장 · 경험치 · 파트너 진화 거리 |

### 2-5. 레벨 10 코스 만들기 (원문 12)
- 경험치: 1km = 10 · 산책 완료 = 30 · 함께 걷기 완료 = 60 · 리뷰 = 10 → 레벨 표 (C 와 B 가 맞춤)
- 레벨 10: 스팟 2~5곳 + 제목 + 소개 → AI 검사 → 공개 코스 목록 → 다른 사람이 고르고 좋아요
- AI 추천 후보에 인기 사용자 코스를 섞음

- 심사 포인트의 AI 활용이 **추천(이유) · 매칭(짝·스몰토크) · 안전(인상착의·리뷰·쪽지 검사)** 세 갈래로 분명해집니다.
