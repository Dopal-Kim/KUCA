## 1. 배포 전 점검 (팀, 10분)

| 확인 | 누가 | 어떻게 | 왜 |
| --- | --- | --- | --- |
| main 의 최신 서버가 Azure 에 올라갔는지 | C (또는 B) | `server/deploy-azure.sh` | 출입 제한 스팟 제외 · 새 소개글은 서버 배포 뒤에 나온다 |
| 가상 상대 켜기 `Match__DemoPartner=true` | C | Azure 앱 설정 | 테스터가 적으면 매칭 상대가 없다. 가상 상대는 성사율 집계에서 빠진다 |
| 날씨 키 `Kma__ServiceKey` | C | `KMA_KEY=... ./deploy-azure.sh` | 비 오는 날 실내 추천 · 날씨 스몰토크 |
| `/api/admin/health` 가 모두 `true` | C | 관리자 키로 호출 | `aiKey` · `weatherKey` · `demoPartner` · `devLoginOff` |
| 서버 첫 응답이 느린지 | C | 앱을 한동안 안 쓴 뒤 추천 눌러 보기 | 20~30초면 시범 기간만이라도 B1 (항상 켜짐) 검토 |

## 2. 빌드 · 배포 (A, 30분)

1. 최신 `main` 받기 → Unity 로 열기 → Console 에 빨간 오류가 없는지 확인
2. 메뉴 **KUCA › 안드로이드 APK 빌드** → 서명 키 · 비밀번호 → **빌드 → KUCA-1.0.0-N.apk**
   - 버전 이름(1.0.0)은 iOS TestFlight 와 같이 쓰므로 그대로 두고, 버전 코드(N)만 오른다
3. Firebase 콘솔 → App Distribution → **테스터 및 그룹** → 그룹 `kuca-pilot` 만들기 (처음 한 번) → 테스터 메일 붙여 넣기
4. 릴리스 탭에 APK 끌어다 놓기 → 그룹 `kuca-team` 과 `kuca-pilot` 둘 다 선택 → 출시 노트 붙여 넣기 → **배포**
5. 바뀐 `ProjectSettings.asset` (버전 코드) 커밋: `Android 1.0.0-N 시범 배포`

**출시 노트 (붙여 넣기용)**
```
KUCA 시범 운영 1회차
- 산책 추천: 15 · 30 · 60분, 지금 시간 · 계절 · 날씨에 맞춘 AI 코스 (식후 산책 버튼)
- 함께 걷기: 근처에서 같은 시간에 걷고 싶은 학생과 만남 스팟에서 만나기
- 걸으면 티켓 → 경희몬 뽑기, 파트너가 걸은 만큼 진화
문제가 있으면 앱 설정 화면 캡처와 함께 단톡에 알려 주세요.
```

## 3. 모집 · 설치 안내

**모집글 (붙여 넣기용)**
```
[경희대 국캠 산책 앱 KUCA 시범 테스터 모집]
공강에 캠퍼스를 걷고, 같은 시간에 걷고 싶은 학생과 함께 산책하는 앱을 만들고 있어요.
1주일 동안 써 보고 마지막에 5분 설문에 답해 주실 분을 찾습니다.

- 대상: 국제캠퍼스 학생, 안드로이드 폰 (아이폰은 TestFlight 로 따로 안내)
- 할 일: 1주 동안 산책 2번 이상 (혼자 1번 · 함께 걷기 1번 권장) + 사후 설문
- 신청: (구글 폼 링크) — 구글 계정 메일을 받습니다
- 받는 정보: 앱 설치 초대를 보낼 구글 메일 (Firebase 로 초대에만 쓰고 시범이 끝나면 지웁니다)
```

**설치 안내 (신청자에게)**
1. 메일함의 Firebase 초대 → **시작하기** → 구글 계정으로 수락
2. 안내에 따라 **Firebase App Tester** 설치 → KUCA **다운로드** → "출처를 알 수 없는 앱" 허용 → 설치
3. 앱을 열고 카카오 · 이메일로 로그인 (체험 계정은 7일 뒤 지워져 시범 기간 기록이 사라질 수 있으니 **로그인 권장**)
4. 위치 권한 허용 (산책 거리 · 근처 매칭에 씀)

## 4. 1주 사용 미션 (단톡에 공지)

| 날 | 미션 |
| --- | --- |
| 1일차 | 설치 · 로그인 · 시작 파트너 고르기 |
| 2~3일차 | 점심 · 저녁 뒤 **식후 산책** 추천 받아 걷기 → 완료 · 코스 별점 |
| 4~5일차 | **함께 걷기** 신청 (정해진 시간대에 단톡으로 같이 신청하면 실제 학생끼리 만남) |
| 6~7일차 | 티켓으로 뽑기 · 파트너 진화 · 파트너와 사진 |

- 함께 걷기는 실제 상대가 없으면 가상 상대가 나온다. **같은 시간대 신청**(예: 수 · 목 12:30)을 정해 실제 매칭이 몇 번은 일어나게 한다.
