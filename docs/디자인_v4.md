# KUCA 디자인 v4 — 전면 개편 기준

> A 작성 · 2026-10-24. v3(민트 그라데이션 · 작은 글자 · 가운데 모은 배치)를 버리고 다시 짠다.
> 코드는 `KucaTheme`(색 · 크기) + `UIKit` v4 부품(`CreatePage` · `PrimaryButton` · `CardBox` · `StatRow` · `Chip` · `EmptyState` · `ListGroup` · `ListRow`)만 쓴다.
> 기능은 그대로, 보이는 방식만 바꾼다.

## 0. 왜 바꾸나 (PC 캡처 27장 · 5184a60 기준 진단)

| 문제 | 근거 (캡처) | v4 답 |
| --- | --- | --- |
| 글자가 작다: 본문 32px = 10.7pt, 보조 24~28px | 산책 기록 · 산책 완료 · 설문 글자가 폰에서 안 읽힘 | 본문 44px(15pt), 최소 32px, 제목 66px |
| 글꼴이 내장 Arial → 한글은 OS 대체 글꼴 (얇고 들쭉날쭉) | 전 화면 | **Pretendard** Medium/Bold 동봉 (OFL) |
| 화면마다 옅은 민트 그라데이션 + 가운데 모은 작은 요소 → 넓은 빈 공간, 위계 없음 | 경희몬 메뉴 위 55% 빈칸, 함께 걷기 · 사진첩 · 기록 | 회색 바탕 + 흰 카드, **큰 왼쪽 정렬 제목**, 내용은 위에서부터 채움 |
| 버튼이 작고 모양이 제각각 (알약 · 원 · 글자) | 산책 완료 3종, 경희몬 원형 버튼 | **아래 꽉 찬 168px 주요 버튼 하나** + 회색 보조 버튼 |
| 닫기 위치 5가지 | 리뷰 P2-11 | 전체 화면은 **왼쪽 위 ‹ 뒤로** 하나 (+ 안드로이드 뒤로) |
| 빈 화면이 "없어요" 로 끝남 | 사진첩 · 가방 · 기록 | `EmptyState`: 제목 + 설명 + 다음 행동 버튼 |

## 2. 토큰 (KucaTheme v4)

- 색: 바탕 `Surface #F2F4F6`, 카드 `Card #FFF`, 보조 버튼 · 입력 `Fill #F2F4F6`, 선 `Line #E5E8EB`, 글자 `Ink #191F28` / `InkMuted #4E5968` / `InkSoft #8B95A1`, 강조 `Primary #2B7A4B` (하나만), 옅은 강조 `PrimarySoft`, 별 · 보상 `Gold #F2B630`, 경고 · 배지 `Crimson #A6192E`.
- 글자: `Display 96` 큰 숫자 · `Title 66` 화면 제목 · `Heading 50` 카드 제목 · `Body 44` 본문 · `Label 38` 칩 · 보조 · `Caption 32` 최소. 굵게는 `UIKit.Bold(text)` (Pretendard Bold).
- 간격: 좌우 `Gutter 60`, 카드 안 48, 카드 사이 32, 누르는 것 최소 `TouchMin 132`, 주요 버튼 `ButtonHeight 168`.
- 모양: 카드 모서리 약 48, 버튼 약 40 (`HudIcons.Rounded` sliced), 칩만 알약.

## 3. 화면 짜는 법 (모든 새 화면 · 고친 화면)

1. `UIKit.CreatePage(canvas, 이름, "큰 제목", 뒤로, "부제", bottomButtons: 1)` 로 틀을 만든다 — 뒤로 ‹ · 안드로이드 뒤로 · 회색 바탕 · 스크롤이 함께 온다.
2. `page.content` 에 `CardBox` · `ListGroup` · `StatRow` · `EmptyState` 를 위에서부터 쌓는다. 가운데 정렬로 띄우지 않는다.
3. 할 일 하나는 `page.bottom` 에 `PrimaryButton`. 보조가 있으면 `SecondaryButton` 을 그 아래.
4. 색 · 크기 숫자를 쓰지 않는다 (`KucaTheme` 만). 없는 부품은 `UIKit` 에 먼저 넣는다.
5. 바꾼 뒤 `UiCapture.Run` 으로 찍어 1장 표와 비교하고 `docs/인터페이스_기준.md` 사이클 기록에 한 줄.
