# KUCA 개인정보 처리방침

시행일: 2026년 10월 24일

KUCA(경희대학교 국제캠퍼스 산책 앱, 이하 "앱")는 경희대학교 학생 팀이 공모전용으로 만든 앱입니다.
앱이 어떤 정보를 왜 받고, 어디에 두고, 언제 지우는지 알려 드립니다.

## 1. 받는 정보와 쓰는 곳, 보관 기간

| 정보 | 쓰는 곳 | 보관 기간 |
| --- | --- | --- |
| 경희대 메일 주소 | 경희대 학생인지 확인 (인증 메일 발송) | 탈퇴할 때까지 |
| 카카오 · Apple 로그인 식별값 | 로그인 | 탈퇴할 때까지 |
| 닉네임 | 메모 · 산책메이트에 표시 | 탈퇴할 때까지 |
| 성별 | 산책메이트 "동성만" 조건에만 씀. 다른 사람에게 보이지 않음 | 탈퇴할 때까지 |
| 산책 취향 (시간대 · 속도 · 좋아하는 것 등) | 산책 추천 · 산책메이트 찾기 | 탈퇴할 때까지 |
| 위치 | 기기에서 지도에 내 위치 표시. 산책 추천을 받을 때 지금 좌표를 서버에 보내지만 **저장하지 않음**. 산책메이트를 찾을 때는 **건물 단위로만** 보냄 | 추천: 저장 안 함 · 매칭: 대기를 취소하거나 매칭이 끝나면 바로 삭제 |
| 인상착의 (예: "회색 맨투맨") | 만나기로 한 상대에게만 보임 | 매칭이 끝나면 바로 삭제 |
| 사진 · 메모 · 댓글 | 경희스팟 메모판에 공개 | 직접 지울 때까지 (탈퇴하면 함께 삭제) |
| 산책 기록 · 리뷰(코스 별점 · 한 줄) · 경험치 | 보상, 추천 품질 집계. 리뷰는 다른 사람에게 보이지 않음 | 탈퇴할 때까지 |
| 매칭 기록 (두 계정 · 만남 장소 · 시각 · 끝난 이유) | 신고 · 차단 처리, 성사율 집계 | 30일 |
| 신고 내용 | 안전 | 90일 |
| 차단 목록 | 차단한 사람과 다시 매칭되지 않게 | 탈퇴할 때까지 |
| 체험 계정 ("로그인 없이 둘러보기") | 로그인 없이 앱 체험 | 만든 지 7일 뒤 자동 삭제 |

- 앱이 카메라로 찍은 사진은 메모판에 올릴 때만 서버로 보냅니다. 올리지 않은 사진은 기기에만 남습니다.
- 집계(추천 수락률 · 매칭 성사율 등)에는 누가 했는지 남기지 않고 종류와 개수만 남깁니다.

## 2. 처리를 맡기는 곳

| 맡기는 곳 | 하는 일 |
| --- | --- |
| Microsoft Azure (App Service · Communication Services) | 서버 운영과 데이터 보관, 인증 메일 발송 |
| 경희대학교 FactChat AI 게이트웨이 (전달은 Amazon Web Services Lambda 를 거침) | 산책 추천 이유 · 대화 주제 만들기, 메모 · 사진 · 리뷰 · 인상착의의 부적절한 내용 검사. 계정 정보는 보내지 않음 |
| 기상청 단기예보 API | 캠퍼스 날씨 확인 (개인정보를 보내지 않음) |
| 카카오 · Apple | 소셜 로그인, 카카오톡 공유 |

## 3. 정보 지우기 (회원 탈퇴)

- 앱의 **설정 › 회원 탈퇴**에서 언제든 계정을 지울 수 있습니다.
- 탈퇴하면 위 표의 정보(메모 · 사진 · 산책 기록 · 매칭 기록 · 차단 목록 포함)를 모두 지웁니다.
- 메모 하나만 지우려면 메모판에서 직접 지울 수 있습니다.

## 4. 만 14세 미만

앱은 대학생을 위한 앱이며 만 14세 미만 아동의 정보를 일부러 받지 않습니다.
