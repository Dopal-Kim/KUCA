# 심사위원에게 KUCA 를 보여 주는 절차 (마감 10/30 금)

> B 작성 · 2026-10-26 · 앱 1.0.0 (빌드 3) · 서버 https://kuca-memo.azurewebsites.net
> 심사위원은 **아이폰 = TestFlight 공개 링크**, **안드로이드 = Firebase App Distribution** 으로 설치한다.
> 둘 다 안 되는 경우를 위해 **3분 시연 영상**을 제출물에 같이 넣는다.

```
① 빌드 3 올리기 (B, 10/26)  →  ② 팀원 확인 (팀, 10/26)  →  ③ 외부 검토 제출 (B, 10/27 오전 ← 가장 중요)
→  ④ 공개 링크 켜기 (B, 통과하면)  →  ⑤ 처음부터 설치해 보기 (팀, 10/29)  →  ⑥ 제출 (10/30)
```

## 3. 심사위원 체험 안내 (제출서 · 발표 마지막 장에 붙여 넣기)

```
[KUCA 체험 방법 · 약 5분]

설치
- 아이폰: App Store 에서 "TestFlight" 앱을 받고 → 아래 링크를 누르면 KUCA 가 설치됩니다.
  (TestFlight 링크)
- 안드로이드: 아래 링크에서 KUCA 를 받아 설치합니다. ("출처를 알 수 없는 앱" 허용이 필요할 수 있어요)
  (Firebase 링크)

시작
1. 앱을 열고 "로그인 없이 둘러보기"를 누르세요. (체험 계정 · 7일 뒤 자동 삭제)
2. 성별을 고르고 산책 취향을 고르면, 첫 파트너 경희펫을 받습니다.
3. 캠퍼스 밖이라면 "가상 산책"을 켜세요. 화면 아래 조이스틱으로 국제캠퍼스를 걸을 수 있어요.
   (안내가 안 뜨면: 오른쪽 위 ⚙ 설정 › 가상 산책 켜기)

꼭 보실 것
- AI 산책 추천: 가운데 "산책 시작" → 출발 · 도착 · 시간 · 취향 → "AI 코스 3개 추천 받기"
  → 지도에서 색이 다른 코스 3개와 장소별 추천 이유를 비교하고 하나를 골라 걸어 보세요.
- AI 산책메이트: 아래 "함께" → 시간 · 상대 조건 → "산책메이트 찾기"
  → 심사 기간에는 시연용 상대 "체험메이트"가 나와, 수락 → 만남 스팟 → AI 대화 주제 → 함께 걷기까지 체험할 수 있어요.
- 산책 완료: 걸은 길 지도 · 보상 · 코스 별점, "카카오톡으로 자랑하기"로 산책 기록 공유
- 경희펫: 아래 "경희펫" → 걸어서 모은 티켓으로 새 친구 만나기 · 도감 · 진화
- 장소 공지: 지도의 건물(경희스팟)을 누르면 그 단과대 · 도서관 공지를 AI 가 요약해 보여 줍니다.
```

## 4. 직접 해 보는 순서 (팀원 확인 · 10/29 리허설 · 시연 영상 공통)

| # | 화면 | 누를 것 | 확인할 것 |
| --- | --- | --- | --- |
| 1 | 로그인 | "로그인 없이 둘러보기" | 성별 · 취향 · 첫 파트너까지 막힘 없이 |
| 2 | 지도 | (캠퍼스 밖) 가상 산책 켜기 | 조이스틱으로 걸어지고 아래 판이 조이스틱을 가리지 않음 |
| 3 | 산책 시작 | 출발 "내 위치" · 도착 "출발지로 돌아오기" · 30분 · 취향 2개 → AI 코스 3개 | 코스 3개 색이 다름, 이유에 건물 안 이야기 없음, 장소 2~4곳 |
| 4 | 코스 걷기 | 코스 고르기 → 걷기 | 다음 장소까지 진한 선 + 화살표, 경로 켜짐/꺼짐, 끝내기 확인창 |
| 5 | 완료 | 끝내기 | 걸은 길 지도 · 보상 · 별점 · 카카오톡 공유 (카톡 카드의 "산책 기록 보기"가 열리는지) |
| 6 | 함께 | 30분 · 상관없어요 → 찾기 | 체험메이트가 나옴 → 수락 → 만남 스팟 → AI 대화 주제 → 함께 걷기 → 끝내기 |
| 7 | 경희펫 | 새 친구 만나기 · 도감 | 화면이 잘리거나 글자가 넘치지 않음 (세로로 긴 폰 포함) |
| 8 | 기록 | 지난 산책 하나 | 지도로 다시 보기 · 공유 |
| 9 | 나 · 설정 | 꾸미기 (얼굴 · 색 · 옷), 설정 | 색 칸이 눌림, Apple 로그인 버튼(로그아웃 후)에 로고 |

## 5. 막혔을 때

| 상황 | 대처 |
| --- | --- |
| 앱이 "서버에 연결할 수 없어요" | 20~30초 뒤 "다시 시도" (서버가 깨어나는 중). 계속이면 `https://kuca-memo.azurewebsites.net/api/health` 확인 |
| 산책메이트가 안 잡힘 | `/api/admin/health` 의 `demoPartner` 확인 → 꺼져 있으면 Azure 앱 설정 `Match__DemoPartner=true` |
| AI 코스 이유가 단순함 | AI 실패 시 규칙 추천으로 바뀐 것 (기능은 정상). 다시 추천 받기 |
| 체험 계정이 지워짐 | 7일 지나면 자동 삭제. 다시 "로그인 없이 둘러보기" |
| TestFlight 링크가 "테스터 가득 참" | 공개 링크 인원 제한(최대 10,000) 확인 · 그룹 설정에서 늘리기 |
| 검토가 늦어짐 | 제출서에 시연 영상 + 안드로이드 링크를 먼저, 아이폰은 "검토 중" 으로 안내 |

## 6. 끝나면

- 공모전 결과 발표 뒤 `.github/workflows/keep-server-awake.yml` 지우기 (서버 깨우기 끄기)
- 시연용 상대 끄기 (`Match__DemoPartner=false`) — 실제 학생 매칭과 섞이지 않게
- TestFlight 빌드는 90일 뒤 만료 (계속 쓰려면 새 빌드)
