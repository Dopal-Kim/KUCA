# 지도 구조물 개선 사이클 (실사 기준)

> A 작성 · 2026-10-24 시작. 캠퍼스 지도의 건물 · 광장 · 도로 · 조경을 **실제 경희대 국제캠퍼스(경기도 용인시 기흥구 덕영대로 1732)** 와 비교해 고친다.
> 지도 생성기는 `tools/keyart` (Python), 결과는 `My project/Assets/Art/KeyArt`. 색 · 창 설정은 `KeyArtLook.json`.

## 0. 확인 방법 (매 사이클)

| 단계 | 도구 | 무엇을 |
| --- | --- | --- |
| 실사 | 경희대 공식 캠퍼스맵 VR (2024 여름 360° · 항공) · 공식 층별 안내 | 재질 · 색 · 층수 · 지붕 · 입구 · 주변 |
| 빠른 확인 | `tools/keyart/preview/turntable.py <건물>` | 웹 미리보기로 북 · 동 · 남 · 서 (35°) + 위 (80°) |
| 실제 앱 | Unity 메뉴 **KUCA › 구조물 사방 캡처** (`-executeMethod UiCapture.RunMap`) | 이름 있는 건물마다 사방 + 위, Unity 셰이더 그대로 |
| 기준 | 아래 1장 원칙 · 2장 점검표 | 어색한 곳 표시 → 다음 사이클 |

실사 사진은 © 경희대학교로 내부 비교에만 쓰고 저장소에는 넣지 않는다 (출처 주소만 남긴다).

## 2. 어색함 점검표

- [ ] 실제와 다른 재질 · 색 · 층수 · 지붕 모양
- [ ] 떠 있거나 묻힌 물체, 지면과 칼로 자른 듯한 접지
- [ ] 두께 없는 지붕 · 캐노피, 뒷면이 비는 면
- [ ] 15 m 넘는 민벽, 같은 창 패턴의 끝없는 반복, 모서리에 걸린 창
- [ ] 너무 큰/작은 문, 입구가 길 반대쪽
- [ ] 건물 안의 나무, 벽을 뚫는 소품
- [ ] 모가 난 연못 · 호수, 같은 나무가 고르게 흩어진 잔디
- [ ] 튀는 채도 (특히 잔디)
