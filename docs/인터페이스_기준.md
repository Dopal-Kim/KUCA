# KUCA 인터페이스 기준 (살아 있는 문서)

> A 작성 · 2026-10-24 시작. 화면을 새로 만들거나 고칠 때 **이 문서부터 본다.**
> 색 · 글자 · 간격은 `KucaTheme.cs` (설계: `docs/디자인_v3.md`), 이 문서는 **화면을 어떻게 짜는가**를 정한다.
> 개선 사이클 기록은 맨 아래 "사이클 기록"에 쌓는다.

## 0. 새 기능 · 기능 수정 때 지킬 것 (연계 규칙)

1. **공통 부품만 쓴다.** 화면 코드에서 `new Color(...)` · 글자 크기 숫자를 직접 쓰지 않는다. 색은 `KucaTheme`, 버튼 · 칩 · 카드 · 시트 · 빈 상태는 `UIKit` 의 공통 부품을 쓴다. 없으면 **부품을 먼저 UIKit 에 추가**하고 쓴다.
2. **한 화면에 강조 버튼 하나.** 그 화면의 할 일은 화면 아래 꽉 찬 `Primary` 버튼 하나. 나머지는 보조(옅은 초록) · 테두리 · 글자 버튼.
3. **지도 위 화면은 아래 시트.** 지도를 가리는 새 화면은 손잡이가 있는 아래 시트(반 · 전체 높이)로. 시트는 한 번에 하나.
4. **상태를 다 만든다.** 새 화면은 ① 기본 ② 불러오는 중 ③ 비어 있음 ④ 오류(다시 시도) 네 상태를 모두 갖춘다.
5. **닫기와 뒤로 가기.** 모든 화면은 `BackButton.Attach` 로 뒤로 가기에 닫히고, 위쪽 왼쪽에 같은 모양의 닫기/뒤로 버튼을 둔다.
6. **되돌릴 수 없는 동작은 한 번 더 묻는다** (산책 끝내기 · 탈퇴 · 신고). 확인 창의 "취소"는 이전 상태로 돌아간다.
7. **말투는 짧은 해요체.** 버튼은 동사 2~6자 ("산책 시작", "다시 시도"). 오류는 무엇이 안 됐고 무엇을 하면 되는지 한 줄.
8. **누르는 것은 최소 96px** (1080 기준), 글자는 최소 24px.
9. **캡처로 확인한다.** 화면을 바꾸면 메뉴 **KUCA › UI 화면 캡처** (또는 `-executeMethod UiCapture.Run`) 로 찍어 이 문서의 화면별 체크리스트와 맞춰 보고, 새 화면은 `UiCapture.Script()` 에 한 줄 추가한다.

## 1. 공통 원칙 (우수 사례에서)

| # | 원칙 | 근거 사례 |
| --- | --- | --- |
| 1 | 한 화면 = 한 가지 일 + 아래쪽 꽉 찬 강조 버튼 하나 | 토스 가입 화면, Strava 시작 버튼 |
| 2 | 지도 + 아래 시트 (손잡이 · 반/전체 높이, 지도는 계속 움직일 수 있음) | Google 지도 2024, Apple HIG Sheets, Material Bottom Sheet |

| 4 | 지도는 차분하게, 내 콘텐츠는 또렷하게 (지도 위 버튼에 그림자 · 테두리, 고른 것은 확실히 다르게) | Apple HIG Maps |

| 13 | 첫 설정은 짧게: 진행 막대 · 문항 수 · "나중에 바꿀 수 있어요" | 듀오링고 온보딩 |
| 14 | 안전은 흐름 안에: 공개된 만남 장소 · 동성만 · 신고/차단은 늘 한 번에 | Bumble 안전, Strava Beacon |
| 15 | 수집은 빈칸을 보여 준다: 실루엣 · 번호 · x/24 | 포켓몬 도감 |
| 16 | 기대감은 정직하게: 등급 힌트 → 공개, 확률 공개 · 걸어서만 얻는 티켓 | 가챠 연출 연구 |
| 17 | 같은 모양은 같은 동작 (여러 개 고르는 칩은 늘 여러 개) | AllTrails 칩 혼동 |
| 18 | 한 목소리: 짧은 해요체 | 토스 UX 라이팅 |

## 2. 화면별 체크리스트

### 지도 HUD
- [ ] 지도는 늘 움직일 수 있다 · 지도 위 버튼은 흰 원 + 그림자 + 이름표
- [ ] 위 왼쪽 프로필, 오른쪽 버튼 3개 (산책 · 기록 · 설정), 아래 공지 · 경희몬(가운데) · 파트너 카드
- [ ] 파트너 카드는 살아 있음 (진화 막대 · 남은 거리) · 누르면 경희몬
- [ ] 공지 카드는 닫을 수 있다

### 산책 추천
- [ ] 첫 단계는 시간(15 · 30 · 60)만, 취향 칩은 선택(여러 개)
- [ ] AI 생성 중 단계 표시 ("가까운 스팟 찾는 중…"), 실패하면 다시 시도
- [ ] 코스 3개 = 색 맞춘 카드 + 지도 선, 고른 카드만 진하게 · 나머지 흐리게
- [ ] 스팟마다 한 줄 이유, 아래 "산책 시작" 하나

### 자유 산책 · 기록
- [ ] 걷는 중: 큰 시간 · 거리 · 지도 경로, 진행 중 표시
- [ ] 멈춤 → 끝내기 확인, 1분 미만은 버릴지 묻기
- [ ] 기록 목록: 경로 썸네일 · 날짜 · 거리, 비어 있으면 "첫 산책 시작" 버튼

### 함께 걷기
- [ ] 대기열 들어가기 전에 안전 카드 (공개 장소 · 동성만 · 신고/차단)
- [ ] 기다리는 동안 솔직한 대기 표시 + 늘 보이는 취소
- [ ] 제안: 공통 취향 · 남은 시간, 수락/거절 같은 크기
- [ ] 만남 스팟은 지도 핀 + 그 자리 경희몬, 대화 주제는 카드
- [ ] 신고/차단은 모든 단계에서 한 번에

### 산책 완료
- [ ] 파트너와 축하 → 큰 숫자 (거리 · 시간 · 들른 곳) → 보상 하나씩 (티켓 · 경험치 · 진화 막대)
- [ ] 코스 별점은 한 번 누르기 (선택), 아래 "완료" 하나 · 공유는 보조

### 경희몬 (파트너 · 뽑기 · 도감 · 진화 · 꾸미기)
- [ ] 파트너: 진화 막대 · 다음 단계 이름 · 꾸미기 칸
- [ ] 뽑기: 버튼에 비용 (1장 · 5장), 등급 힌트 → 공개, 확률 보기, 두 번째부터 건너뛰기
- [ ] 도감 24: 모은 것은 색, 본 것은 실루엣, 못 본 것은 번호, x/24
- [ ] 진화 연출은 건너뛰기 · 다시 보기

### 캐릭터 꾸미기
- [ ] 위 절반 3D 미리보기 (드래그 회전), 얼굴 탭은 얼굴 확대
- [ ] 탭 (얼굴 · 색 · 옷), 고른 것은 테두리로 확실히
- [ ] 랜덤 · 완료 아래 고정, 저장 안 하고 나가면 묻기

### 장소 메모
- [ ] 건물 핀에 메모 수, 누르면 장소 시트
- [ ] 메모 카드: 사진 · 글 · 좋아요 · 댓글, 신고는 카드마다
- [ ] "메모 남기기" 하나, 비어 있으면 "첫 메모를 남겨 보세요"

### 로그인 · 첫 설정
- [ ] 카카오 · Apple · 이메일 버튼 같은 크기, 카카오는 #FEE500 · 검은 말풍선
- [ ] "둘러보기" 보이게, 로그인은 필요할 때
- [ ] 설문: 한 화면 한 문항 · 진행 막대 · "나중에 바꿀 수 있어요" · 건너뛰기

### 설정
- [ ] 묶음 목록: 계정 · 함께 걷기 안전 · 화면(계절 테마) · 개인정보 · 정보
- [ ] 토글은 바로 저장, 위험한 동작은 크림슨 + 확인
