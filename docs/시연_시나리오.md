## 3. 심사위원 체험 안내 (앱 설명란 · 발표 마지막 장)

```
1. 앱 실행 → "체험으로 시작" → 파트너 고르기
2. 캠퍼스 밖이면 "가상 산책" 켜기 (설정에서도 가능) → 화면 조이스틱으로 걷기
3. 산책 → 추천 코스 → AI 코스 받기 → 걸어서 완료
4. 산책 → 함께 걷기 → 같이 걸을 사람 찾기 (심사 기간엔 가상 상대가 5초 뒤 나옵니다)
```

## 4. 막히면 (대체 경로)

| 상황 | 대체 |
| --- | --- |
| 서버가 늦게 깸 · 인터넷 끊김 | 추천은 앱 기본 코스로, 완료는 기기에서 판정 (서버 없이도 동작) → 그 장면만 다시 찍기 |
| AI 응답 실패 | 규칙 추천으로 자동 대체 (화면은 같음). 이유 문장이 단순하면 다시 찍기 |
| 가상 상대가 안 나옴 | `/api/admin/health` 의 `demoPartner` 확인 → C 에게 켜 달라고 |
| 진화 장면이 안 나옴 | 미리 걸어 둔 계정으로 0.2km 더 걷기 |
