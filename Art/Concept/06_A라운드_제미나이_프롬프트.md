# A 라운드 그래픽 — 제미나이 프롬프트 모음

팀원 A(아트·캐릭터·출현 규칙)의 라운드 A-1 ~ A-4 에 필요한 이미지·3D 레퍼런스·화면 그래픽을 제미나이로 만들기 위한 프롬프트입니다.
캐릭터 원본 설정은 `05_Characters/캐릭터_기획_및_제미나이_프롬프트.md` 를 따릅니다.

## 원칙 — 모든 이미지는 KUCA 구동 화면과 어울려야 한다

새로 만드는 모든 이미지(아이콘·화면 시안·분위기·발표 자료)는 **지금 구현된 KUCA 게임 화면의 그림체·색·밝기와 이어져야** 합니다.
따로 보면 예뻐도 게임 화면 옆에 놓았을 때 다른 게임처럼 보이면 다시 만듭니다.

- **기준 화면 (항상 첨부):** `tools/keyart/preview/shots/campus_wide.png` — 게임이 그리는 지도 그대로(키아트 렌더러 결과). 실제 Unity 스크린샷이 생기면 그것으로 바꿉니다.
- **캐릭터 기준:** `tools/keyart/preview/shots/fig_<id>.png` (게임에 들어간 3D 피규어 렌더), `05_Characters/images/` (원본 시트)
- **지도 분위기를 바꾸는 이미지**(시간대·계절·날씨)는 새로 그리지 않고 **기준 화면을 편집**합니다: 같은 카메라·배치·건물, 빛·계절·날씨만 바꿈.
- **게임 UI 색 (코드에서 쓰는 값):**

| 쓰임 | 색 |
| --- | --- |
| HUD 유리 패널 / 테두리 빛 | 짙은 남색 `#101A3A` (80% 불투명) / 하늘색 `#8CD1FF` |
| 강조 | 크림슨 `#DB3840` · 금 `#D9B873`, `#F5C973` · 경험치 분홍 `#ED7393` |
| 도감·메뉴 | 민트 그라데이션 `#F5FCF8 → #D9F2E6` · 청록 `#1A545E`, `#2B737D` · 민트 `#61DBB3` |
| 메인 메뉴 | 하늘 `#9ED1FF → #143D9E` · 남색 `#1A3885` |
| 쪽지판 | 종이 `#E6E6E3` · 메모지 `#FFFAE8` · 잉크 `#1C1C1F` |

- 제미나이 호출은 `tools/keyart/gemini_image.py` 로 하고, 쓴 프롬프트는 `Art/Concept/06_A_Round/prompts/` 에 남깁니다.

## 0. 쓰는 법

1. **레퍼런스 이미지를 같이 올립니다.** 제미나이는 첨부 이미지를 보고 그림체를 맞춥니다. 각 프롬프트의 `첨부` 줄에 적힌 파일을 함께 올리세요.
   - 캐릭터: `05_Characters/images/<등급>/<번호>_<이름>_model.jpg` (턴어라운드), `..._card.jpg` (도감 카드)
   - 캠퍼스 분위기: `04_System_and_Visuals/[캠퍼스 전경] - [발표 메인 비주얼]_16x9.png`
   - UI 분위기: `04_System_and_Visuals/[시스템 UI] - [쪽지 마커 3종]_아이콘.png`
2. **블록을 순서대로 붙입니다.** `공통 블록` → (필요하면) `등급 블록` → 작업별 블록. 프롬프트에는 ``` 안의 영어만 붙입니다.
3. **글자는 넣지 않습니다.** 제미나이가 그린 한글은 깨지기 쉽습니다. 이미지에는 글자 자리만 비우고, 글자는 Unity 에서 얹습니다.
4. **한 번에 한 장.** 마음에 안 들면 같은 대화에서 "same image, but ~" 로 고칩니다. 새 대화로 가면 그림체가 흔들립니다.
5. **3D 모델은 제미나이가 직접 만들지 않습니다.** 제미나이로 만든 턴어라운드 시트(정면·측면·뒷면)를 Claude 에게 주면 `tools/keyart/kuca_art/figs/` 의 파이썬 조형 코드로 3D 를 만듭니다.
6. **저장 규칙** — `Art/Concept/06_A_Round/<카드번호>_<내용>_<변형>.png` (예: `A1_조건아이콘_시간대.png`, `A2_희귀_library_owl.png`). 기존 README 의 브래킷 규칙을 따라도 됩니다.
7. `<꺾쇠>` 부분은 작업자가 정해서 바꿔 넣는 자리입니다.

## 2. A-1 시공간 한정 출현

정해진 것: 조건은 **순수 확률 가중**(조건이 맞으면 더 자주, 안 맞으면 드물게 — 아예 안 나오지는 않음), 시간대는 **아침·낮·저녁·밤 4구간**, **24종 모두** 적용하고 황금 동물은 더 뚜렷하게, 날씨는 **기상청 예보·실황**으로 반영.

### 2-1. 출현 조건 아이콘 세트
첨부: 쪽지 마커 아이콘
```
[UI STYLE]
OUTPUT = ICON SHEET:
A 4 x 3 grid of square game icons on a plain light background, evenly spaced, each icon centered in its cell, same size and style.
Row 1 (time of day): early morning sunrise, bright midday sun, sunset dusk, night moon with stars.
Row 2 (season): spring cherry blossom, summer green leaf with sun, autumn red maple leaf, winter snowflake.
Row 3 (weather): clear sky, soft cloud, rain drops with umbrella, snow.
Each icon is a rounded badge with a soft colored circle background that fits its meaning.
```
- 낱개가 필요하면 `OUTPUT = SINGLE ICON: one square icon of <내용>, centered, plain light background.` 로 바꿉니다.

### 2-2. 시간대별 캠퍼스 분위기 (지도 색감 기준)
지도 셰이더(`KeyArtLook`)의 시간대 색을 맞출 때 기준 이미지로 씁니다. 같은 대화에서 4장을 차례로 만듭니다.
첨부: 발표 메인 비주얼
```
[SCENE STYLE]
OUTPUT = MOOD FRAME, 16:9.
Same campus, same camera and composition as the attached key art. Only the time of day changes:
<early morning: pale gold low sun, long soft shadows, light mist>
Keep the scene bright and friendly even when dark; colors must stay clearly readable.
```
`<...>` 부분을 차례로 바꿉니다:
- `midday: clear bright sun, short shadows, vivid colors`
- `sunset: warm orange-pink sky, glowing windows starting to light up, long shadows`
- `night: deep blue sky with stars, warm glowing windows and street lamps, soft moonlight, still cute and readable`

### 2-3. 계절별 캠퍼스 분위기
```
[SCENE STYLE]
OUTPUT = MOOD FRAME, 16:9.
Same campus, same camera and composition as the attached key art. Only the season changes:
<spring: pink cherry blossom trees along the paths, petals on the lawns>
```
- `summer: lush deep green trees, strong sun, clear blue sky`
- `autumn: red and orange maple trees, golden ginkgo trees, fallen leaves on paths`
- `winter: light snow on roofs and lawns, bare trees with a few evergreens, crisp pale sky`

### 2-4. 날씨 연출 참고 (비·눈 이펙트)
```
[SCENE STYLE]
OUTPUT = MOOD FRAME, 16:9.
Same campus as the attached key art on a <rainy> day: soft visible rain streaks, small puddles reflecting buildings,
slightly muted but still bright colors, cozy mood. Show how weather looks in this toy-diorama style.
```
`<rainy>` → `snowy` 로 한 장 더.

### 2-5. 도감 "출현 조건" 힌트 화면 목업
B(화면 담당)와 함께 볼 시안입니다. 아직 못 만난 동물을 실루엣으로 보여 주고 조건 아이콘으로 힌트를 줍니다.
첨부: 도감 카드 1장 (예: `10_LibraryOwl_card.jpg`), 2-1 결과
```
[UI STYLE]
OUTPUT = MOBILE SCREEN MOCKUP, portrait 9:19.5 phone screen.
A collection-book detail popup over a dimmed map. In the popup: a large dark navy silhouette of an undiscovered animal
standing on a round golden-rimmed base, a small mysterious sparkle around it,
below it a row of three condition badges (a night moon icon, an autumn maple leaf icon, a clear sky icon),
and two empty rounded label bars where the name and hint text will go, plus one rounded button at the bottom.
```

### 2-6. 지도 위 "지금만 나오는 동물" 표시
```
[UI STYLE]
OUTPUT = EFFECT SHEET, 3 variations side by side on a light green lawn-colored background, top-down view:
a soft glowing ground ring and gentle light particles marking a special limited-time spawn spot on a map.
Variation 1: golden glow (legendary). Variation 2: moonlight blue glow (night-only). Variation 3: cherry-pink glow (season-only).
Subtle enough not to cover the character standing in the middle (leave the center empty).

## 3. A-2 희귀 색 개체

희귀 확률, 색을 바꾸는 방식(모델 따로 / 셰이더 색조), 연출은 작업자가 정합니다. 아래는 **색 시안**을 빠르게 비교하기 위한 프롬프트입니다.

### 3-1. 희귀 색 비교 시트 (종마다 1장)
첨부: 해당 동물 `_model.jpg` + `_card.jpg`
```
[STYLE]
[RARITY 블록 — 05_Characters 기획서 4절에서 해당 등급]
[CHARACTER 블록 — 05_Characters 기획서 6절에서 해당 동물]
OUTPUT = COLOR VARIANT SHEET, horizontal 16:9, plain white background.
The SAME character twice side by side, same pose (3/4 front view), same base, same outfit and props:
LEFT = normal colors exactly as the attached reference.
RIGHT = a rare "shiny" color variant: <body color change, e.g. pale silver-lavender fur with mint accents>,
outfit and props keep their shapes but shift to harmonizing colors, the base rim gets a pearly iridescent finish,
a few extra tiny star sparkles around the character. Both versions must look like the same toy, only recolored.
```
- `<색 변화>` 는 동물마다 정합니다. 처음엔 "make three different rare color options in a row" 로 3안을 받아 고르면 빠릅니다.
- 셰이더 색조 방식으로 갈 경우: `the rare variant is a uniform hue shift of the whole body` 로 바꿔 실제 구현 결과와 비슷한 시안을 봅니다.

### 3-2. 희귀 개체 획득 연출 화면 목업
첨부: 3-1 결과 중 하나, 잡기 화면 스크린샷(있으면)

OUTPUT = MOBILE SCREEN MOCKUP, portrait 9:19.5.
The moment a rare color variant is caught: the rare character in the center on its base, a burst of iridescent light rays
and floating star sparkles behind it, a soft rainbow ring on the ground, confetti-like small shapes.
An empty rounded banner at the top for the title and an empty rounded button at the bottom.
Celebratory but clean.
```

### 3-3. 희귀 배지 아이콘
```
[UI STYLE]
OUTPUT = SINGLE ICON, square, plain light background:
a small rounded badge with an iridescent pearly star inside, marking a rare color variant in a collection list.
Readable at 48 pixels.

## 5. A-4 발표 비주얼 · 시연 영상

시연 순서와 촬영 방식은 B·C 와 함께 정합니다.

첨부: 발표 메인 비주얼, 카드 이미지 여러 장 (등급별 1~2장씩)
```
[SCENE STYLE]
[STYLE]
OUTPUT = KEY VISUAL, 16:9.
The attached campus diorama key art, with the attached toy animal characters standing at their landmarks around the campus,
each on its small round base, scaled so they read clearly. Golden legendary animals near their buildings,
a few green and blue animals on the lawns and paths. A soft glowing walking route connects several spots.
Bright sunny spring day, cherry blossoms. Leave the upper-left quarter calm and empty for a title.

### 5-2. 캐릭터 라인업 포스터
```
[STYLE]
OUTPUT = LINEUP, horizontal 16:9, soft cream background with a subtle campus silhouette.
All characters from the attached images standing in three tiers like a class photo:
back row 16 golden legendary characters, middle row 4 blue rare, front row 4 green common,
each on its own base, all facing forward, cheerful, evenly lit. Leave an empty band at the top for a title.
```
- 24마리를 한 번에 그리면 섞이기 쉽습니다. 안 되면 등급별로 따로 만들고 합칩니다.

### 5-3. 시연 영상 타이틀·엔딩 카드
```
[SCENE STYLE]
[STYLE]
OUTPUT = TITLE CARD, 16:9.
A close, warm shot of the campus diorama at golden hour with the space rabbit, library owl and campus cat in the foreground
looking at the viewer, a smartphone frame shape floating softly on one side showing a tiny map (no text on it).

```
엔딩 카드: `golden hour` → `night with glowing windows`, 캐릭터들이 손을 흔드는 포즈로.

### 5-4. 기능 설명 일러스트 (발표 슬라이드용)
기능마다 1장. 같은 대화에서 차례로 만듭니다.

small pin markers, a tiny student character holding a phone at the start, a clock and a sun icon floating nearby>
Simple, friendly, explains the idea at a glance. No text.
```
`<...>` 를 바꿔서:
- `Place memos: a landmark with colorful paper notes and small photos pinned around it like a collage, a heart and a speech-bubble shape (no text)`
