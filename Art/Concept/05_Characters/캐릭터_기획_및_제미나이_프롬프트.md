# 캠퍼스 동물 캐릭터 기획 · 제미나이 프롬프트 (v2)

맵에 자동으로 생기는 수집 캐릭터. 희귀도는 초록(흔함) → 파랑(드묾) → 노랑(가장 드묾, 장소마다 다른 동물).
게임 코드 기준 확률: 초록 60% · 파랑 30% · 노랑 10% (`Assets/Scripts/CollectibleSpawner.cs`).

## 1. 정해진 것 (인터뷰)

| 항목 | 결정 |
| --- | --- |
| 컨셉 | 동물, 두 발로 선 의인화 |
| 비율 | 2등신 (머리 = 몸). 탑다운 맵에서 작아도 알아보게 |
| 그림체 | 말랑한 3D 토이 (비닐·클레이 피규어), 키아트처럼 밝고 화사한 색 |
| 희귀도 색 | 동물 본래 색은 살리고, 소품 + 발밑 받침 테두리를 등급 색으로 |
| 받침 | 키아트 건물 아이콘처럼 둥근 잔디 받침 + 석재 테두리, 테두리가 등급 색 |
| 등급 연출 | 단계적: 초록 소품 1개 · 파랑 소품 2개 + 테두리 띠 · 노랑 장소 테마 의상 + 도구 + 금테 + 반짝이 |
| 학교 정체성 | 교표·글자 없이 경희 크림슨을 바늘땀·단추·작은 배지에만 |
| 용도 | 도감 카드(9:16, 위 1/3 비움) + 3D 모델링 레퍼런스(턴어라운드 시트) |
| 카드 배경 | 노랑만 사는 랜드마크 미니어처 배경, 초록·파랑은 등급 색 파스텔 그라데이션 |
| 프롬프트 방식 | 공통 스타일 블록 + 캐릭터별 블록, 캐릭터마다 카드 1장 + 레퍼런스 1장. 영어 프롬프트 + 한국어 설명 |
| 이름 | 동물 이름 그대로 (노랑은 `장소 + 동물`, 예: 공학관 토끼) |
| 도감 소개 | 학교생활 공감 유머 한 줄 |
| 카드 포즈 | 캐릭터마다 자기 도구를 쓰는 동작 |
| 노랑 출현 | 자기 랜드마크 근처에서만. 랜드마크끼리 범위가 절대 겹치지 않게 (아래 9절) |

## 3. 공통 스타일 블록 (모든 프롬프트 맨 앞에 붙임)

```
STYLE (keep identical for every character):
A cute anthropomorphic animal character rendered as a soft 3D toy figure, like a premium vinyl / clay collectible.
Chibi proportion: exactly 2 heads tall (the head is as big as the whole body), standing upright on two short legs,
short stubby arms, round chunky shapes, smooth matte surfaces with a soft subtle subsurface glow,
no individual fur strands, no realistic textures, no hard outlines.
Face: big glossy dark eyes with one white highlight each, tiny mouth, soft pink blush cheeks.
Lighting and color: bright sunny pastel palette matching a cheerful miniature campus diorama,
high brightness, gentle saturation, warm sunlight from the upper left, soft blue-tinted shadows, soft ambient occlusion.
Shapes simple and readable even when very small.
The character stands on a round diorama base: a thick circular grass top with a smooth stone rim,
like a miniature plinth (the rim color shows rarity, see RARITY).
School identity: a tiny Kyung Hee crimson accent only (one small stitch, button or round badge, deep crimson about #A6192E).
Absolutely no text, letters, numbers, logos or watermarks anywhere.
```

## 4. 등급 블록 (공통 스타일 다음에 하나 붙임)

```
RARITY = COMMON (GREEN):
The base rim is soft leaf green (#6CCB5F). Exactly ONE small accessory in the same green.
Simple and plain, no special effects. Dopey, absent-minded, slightly sleepy expression.
```

```
RARITY = RARE (BLUE):
The base rim is sky blue (#4EA8F5) with a thin lighter blue trim line. Exactly TWO small accessories in the same blue.
Slightly more detailed than common, a confident curious expression, no sparkles.
```

```
RARITY = LEGENDARY (GOLD / YELLOW):
The base rim is warm golden yellow (#FFC933) with a polished gold trim line, and a few tiny themed props
decorate the grass top of the base. The character wears a themed outfit and holds a themed tool (see CHARACTER).
A few tiny soft golden sparkles float around the character. Proud, joyful expression. Most detailed of all rarities.
```

## 5. 출력 블록 (용도마다 하나)

### A. 도감 카드 (9:16)
```
OUTPUT = COLLECTION CARD:
Vertical 9:16 image. The top third is left completely empty (only soft background, no objects) for UI text.
The character is centered in the lower two thirds, 3/4 front view, a lively signature pose, full body and base visible.
Background for COMMON/RARE: a smooth pastel gradient of the rarity color with a few soft round bokeh dots.
Background for LEGENDARY: a softly blurred bright miniature diorama of the character's landmark
(described in CHARACTER) in a clean low-poly key-art style, sunny spring day, behind the character.
```

### B. 3D 모델링 레퍼런스 (턴어라운드 시트)
```
OUTPUT = 3D MODEL REFERENCE SHEET:
Horizontal 16:9 character turnaround sheet on a pure white background.
The SAME character shown four times in one row at the same scale, aligned on one baseline:
front view, 3/4 front view, right side view, back view.
Neutral A-pose (arms slightly away from the body, legs straight, mouth closed, eyes open), every accessory worn the same way in all views.
Orthographic-looking camera with no perspective distortion, flat even studio lighting, no cast shadows, no background props.
The round diorama base is shown under each view.
On the far right, the handheld tool / props shown separately and slightly larger.
No text, labels, arrows or color swatches.
```

## 6. 캐릭터 블록 (24종)

각 블록 위의 한국어 줄은 도감용 이름과 소개입니다 (프롬프트에는 넣지 않음).
프롬프트에는 ``` 안의 영어만 붙입니다. `POSE` 는 도감 카드(출력 A)에만 쓰고, 3D 레퍼런스(출력 B)는 A-포즈로 그립니다.
`LANDMARK` 는 노랑 도감 카드 배경에만 씁니다.

### 초록 · 흔함

**비둘기** — 학식 앞에서 기다리면 언젠가 만난다. 아무 생각이 없어 보인다. 실제로 없다.
```
CHARACTER = Pigeon, RARITY = COMMON.
A chubby grey pigeon with a shiny green-purple neck, half-lidded dopey eyes, a tiny beak slightly open.
Accessory: a tiny green pouch of bread crumbs hanging from one wing.
POSE: tossing one crumb into the air and missing it, head tilted.
```

**달팽이** — 1교시 수업에 가는 중이다. 지난 학기부터.
```
CHARACTER = Snail, RARITY = COMMON.
A soft cream-colored snail standing upright, a round caramel swirl shell on its back, two short eye stalks, sleepy half-closed eyes.
Accessory: a big green leaf held like an umbrella.
POSE: slowly walking forward under the leaf umbrella, one eye stalk drooping.
```

**개미** — 자기 몸보다 큰 걸 들고 간다. 어디로 가는지는 본인도 모른다.
```
CHARACTER = Ant, RARITY = COMMON.
A small reddish-brown ant with a big round head, two bendy antennae, confused blank eyes, standing on two legs (the other limbs tiny).
Accessory: a green leaf piece much bigger than itself, carried on its head.
POSE: balancing the leaf on its head and looking the wrong way.
```

**무당벌레** — 벚꽃길에서 자주 넘어진다. 일어나는 데 한참 걸린다.
```
CHARACTER = Ladybug, RARITY = COMMON.
A very round ladybug, glossy red shell with black dots, a black round head, wobbly stance, dazed smile.
Accessory: a tiny green backpack.
POSE: just tipped over and sitting on the ground, backpack straps askew, a single cherry petal on its head.
```

### 파랑 · 드묾

**길고양이** — 캠퍼스의 진짜 주인. 학생증 없이 모든 건물 출입 가능.

POSE: sitting proudly and holding the fish snack up like a trophy.
```

**청설모** — 도토리를 묻어 둔 자리를 매 학기 잊어버린다.
```
CHARACTER = Korean Squirrel (Eurasian red squirrel, dark grey-brown coat), RARITY = RARE.
A grey-brown squirrel with a cream belly, long tufts on the ear tips, a huge fluffy tail curling up behind it.
Accessories: a small blue acorn pouch on a strap, and a tiny blue knit cap.

```

**까마귀** — 반짝이는 걸 모은다. 잃어버린 학생증의 절반은 이 녀석 둥지에 있다.

## 7. 제미나이에 넣는 순서

1. 공통 스타일 + 등급 + 출력 A + 캐릭터 블록을 이어 붙여 한 번에 넣는다.
2. 처음 한 장(공학관 토끼 카드)으로 그림체를 확정한다. 마음에 드는 결과가 나오면,
   이후 프롬프트마다 그 이미지를 첨부하고 첫 줄에 `Match the exact rendering style, proportion and base design of the attached image.` 를 붙인다.
3. 같은 캐릭터의 3D 레퍼런스(출력 B)는 그 캐릭터의 카드 이미지를 첨부해서 만든다 (같은 얼굴·소품 유지).
4. 키아트 아이콘(`01_Buildings`, `02_Landscapes`)을 함께 첨부하면 받침과 랜드마크 배경이 기존 아트와 맞는다.

## 8. 프롬프트 한 장 조립 예 (공학관 토끼 도감 카드)

`공통 스타일` + `RARITY = LEGENDARY` + `OUTPUT = COLLECTION CARD` + `CHARACTER = Engineering Rabbit` 를

## 9. 노랑 출현 규칙 (게임 코드 반영 예정)

- 노랑은 자기 랜드마크 반경 안에서만 생긴다. 반경 밖에서는 노랑 대신 파랑이 나온다.
- 반경 = min(60 m, 가장 가까운 다른 랜드마크까지 거리의 절반 − 5 m) → 두 랜드마크의 범위가 절대 겹치지 않는다.
- 반경 판정은 건물 외곽선 기준 거리 (건물 크기가 달라도 공평하게).
- 디자인 확정 후 `CollectibleSpawner` 에 랜드마크 목록·반경을 넣고, 스폰 위치가 두 범위에 동시에 들지 않는지 검사하는 테스트를 같이 둔다.
